# 项目介绍 — Java 图形化 Git 客户端（类 TortoiseGit）

> 本文是项目的总览入口，介绍产品定位、技术栈、核心功能与目录结构。
> 详细需求见 [PRD](../07-analysis/report/Java图形化Git客户端（类TortoiseGit）产品需求文档.md)，技术规约见 [00-spec/](../00-spec/)。

---

## 项目定位

纯 Java、跨平台（Windows / Mac / Linux）图形化 Git 客户端，功能对标 TortoiseGit。采用「独立启动 + 手动选择 Git 工作目录」模式，无需系统右键菜单依赖。除主窗口外，每个操作（Commit、Pull、Push、Switch、Merge 等）以独立模态对话框弹出，交互方式与 TortoiseGit 一致。

---

## 技术栈

| 层级 | 技术 | 说明 |
| ------ | ------ | ------ |
| 语言 | Java 21 | JDK 21 |
| 框架 | Google Guice | 轻量级 IoC 容器，Module 绑定，启动快、体积小 |
| Git 操作 | JGit（主）+ 本地 Git CLI（兜底） | JGit 纯 Java、进度可控；LFS/Hook/复杂 Rebase 回退 CLI，强制 UTF-8 + `core.quotepath=false` |
| 数据库 | SQLite（sqlite-jdbc + Flyway） | 本地存储，Flyway 管理迁移 |
| GUI | JavaFX 21 | 原生桌面窗口，无 WebView / 无浏览器 |
| 构建 | Maven | 打包 fat jar + bat/sh 启动脚本 |

---

## 与 TortoiseGit 的差异

| 差异点 | TortoiseGit | 本产品 | 原因 |
| -------- | ------------- | -------- | ------ |
| 入口方式 | 资源管理器右键菜单集成 | 独立启动 + 手动选择目录 | 跨平台实现成本，避免系统右键菜单依赖 |
| 是否有常驻主窗口 | 无，每个操作独立对话框 | 有主窗口（导航树 + 内容区） | 独立启动模式下的工作区聚合 |
| Icon Overlay | 系统资源管理器图标叠加 | 不支持 | 跨平台实现成本，无右键菜单集成 |
| 右键菜单自定义 | 支持配置菜单项显隐 | 暂不支持（后续迭代） | 优先实现核心功能 |

## 核心功能概览

- **仓库创建与获取**：Clone / Init / 打开已有仓库
- **多仓库自动检索与收藏**：递归检索目录下所有 Git 仓库，收藏置顶管理
- **仓库状态检查**：修改 / 新增 / 删除 / 未跟踪 / 冲突文件展示
- **Commit / Pull / Push / Fetch / Sync**：完整远程同步与提交
- **分支与标签管理**：Switch / Create / Merge / Delete / Rename
- **Cherry Pick / Rebase / Stash / Revert / Clean up / GC**
- **日志回溯**：版本图、筛选、双栏对比、Reset / Revert / Blame / RefLog
- **文件操作与上下文菜单**：Add / Delete / Rename / Ignore / Lock / Blame / Resolve / Export
- **冲突解决**：内置三栏合并器 + 外部 Merge 工具
- **补丁、Bisect、Submodule、Worktree、LFS、Hook、GPG**：高级功能
- **设置**：Git 配置 / 凭证 / 外部工具 / SSH / 主题 / 语言 / 快捷键
- **命令红线与安全约束**：阻断类 + 二次确认类两级管控（详见 PRD 第八章）

## 非功能需求摘要

- **Git 依赖**：JGit 可独立工作；CLI 兜底场景需本地 Git，启动时检测
- **单实例**：锁文件检测，同一时间只允许一个实例
- **跨平台**：Windows / Mac / Linux 功能与样式统一
- **性能**：大仓库扫描、Diff 对比、日志加载无明显卡顿
- **国际化**：中 / 英切换
- **主题**：浅色 / 深色 / 跟随系统
- **凭证安全**：集成系统 credential helper，不明文存储密码
- **编码处理**：Git 输出统一 UTF-8，Windows 设置 `core.quotepath=false`

## 快速启动

```bash
# 在 app-backend/ 目录执行：
mvn clean package
# 结果：app-backend/target/ 下生成 git-gui-{version}.jar

# 启动（Windows）：
app-backend/scripts/git-gui.bat
# 启动（Mac/Linux）：
./app-backend/scripts/git-gui.sh
```

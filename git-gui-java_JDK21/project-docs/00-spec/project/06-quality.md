# 质量保障 — git-gui 项目专属

> **基座**：继承 [shared/06-quality-base.md](../shared/06-quality-base.md) — 测试策略、BR 覆盖要求、测试模式、Mock 策略、代码门禁、日志规范。
> 本文档为 git-gui 项目专属的可观测性与性能 SLO。

---

## 可观测性

### 应用内状态面板

桌面应用无 HTTP 健康检查端点，通过应用内「状态面板」查看运行状态：

- **最近任务**：从 `task_record` 查询活跃与历史任务（BR-35）
- **操作日志**：从 `operation_log` 查询 Git 操作历史（成功/失败/取消 + 耗时）
- **红线审计日志**：从 `audit_log` 查询命中红线的操作（BR-31）

### 关键指标

- 操作成功率（`operation_log.success`）
- 任务执行耗时（`operation_log.duration_ms`）
- 红线命中分布（`audit_log.rule_code` / `action_result`）
- 异步任务排队与取消情况（`task_record.status`）

## 性能 SLO

| 指标 | 目标 | 说明 |
| ------ | ------ | ------ |
| 多仓库扫描（1000 仓库） | <5s | 异步可取消，不阻塞 UI（BR-02） |
| 状态检查刷新 | <500ms | 中等仓库（<10k 文件） |
| Diff 加载 | <300ms | 单文件 diff |
| 日志加载（单页 200 条） | <1s | 大仓库分页（BR-18） |
| Push / Pull 响应 | 依赖网络 | 进度实时反馈，可取消（BR-33） |
| 冷启动 | <3s | 含 Guice 注入 + Flyway 迁移 |

---

## 稳定性目标

- 常规操作无崩溃、无数据丢失
- 异常有容错处理：Git 操作失败不崩溃，任务失败友好中文提示（BR-35）
- 长任务可取消，取消不破坏仓库状态（BR-33）
- 单实例锁异常退出可恢复（BR-40）

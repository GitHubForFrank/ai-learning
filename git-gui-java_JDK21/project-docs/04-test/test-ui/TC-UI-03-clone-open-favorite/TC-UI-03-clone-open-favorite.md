# TC-UI-03 — 仓库克隆/打开/收藏

## 基本信息

| 项 | 内容 |
| ---- | ---- |
| 用例编号 | TC-UI-03 |
| 类型 | UI 测试（TestFX，headless） |
| 关联 BR | BR-01~BR-05 |
| 关联模块 | BE-01 仓库检索与收藏 |

## 测试目标

验证仓库克隆、打开、收藏与最近仓库列表的 UI 流程。

## 前置条件

- 应用 TestFX headless 启动
- 准备一个可克隆的远程 URL（本地 file:// 仓库）

## 测试步骤

| 步骤 | 操作 | 预期结果 |
| ---- | ---- | --------- |
| 1 | 打开「克隆」对话框，填 URL 与目标目录 | 克隆异步执行，进度对话框可取消 |
| 2 | 「打开仓库」选择非 Git 目录 | 提示 REPO_NOT_GIT |
| 3 | 打开有效仓库 | 仓库加载，加入最近仓库列表 |
| 4 | 收藏当前仓库，设置 alias/group | 收藏列表出现该项 |
| 5 | 重复收藏同一路径 | 提示 DUPLICATE_FAVORITE |
| 6 | 置顶收藏项 | 置顶项排在列表顶部 |

## 整体期望结果

- 克隆/打开/收藏流程正常
- 唯一性与置顶排序生效

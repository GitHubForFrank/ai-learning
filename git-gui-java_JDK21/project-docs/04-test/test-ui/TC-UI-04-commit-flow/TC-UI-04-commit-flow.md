# TC-UI-04 — Commit 提交流程

## 基本信息

| 项 | 内容 |
| ---- | ---- |
| 用例编号 | TC-UI-04 |
| 类型 | UI 测试（TestFX，headless） |
| 关联 BR | BR-06~BR-08 |
| 关联模块 | BE-02 Commit |

## 测试目标

验证 Commit 对话框的提交流程与校验。

## 前置条件

- 应用 TestFX headless 启动，打开有未提交修改的仓库
- Commit 对话框可打开

## 测试步骤

| 步骤 | 操作 | 预期结果 |
| ---- | ---- | --------- |
| 1 | 打开 Commit 对话框，未勾选任何文件 | 提交按钮置灰 |
| 2 | 勾选文件，message 留空 | 提交被拒，提示 message 必填 |
| 3 | 勾选文件 + 填 message，点提交 | 提交成功，状态列表刷新 |
| 4 | Amend 模式 | 复用上次 message，可编辑 |
| 5 | Commit & Push（推送红线阻断） | 提交成功但推送被阻断，提交不回滚 |

## 整体期望结果

- 文件勾选与 message 校验生效
- Commit & Push 推送失败不回滚提交

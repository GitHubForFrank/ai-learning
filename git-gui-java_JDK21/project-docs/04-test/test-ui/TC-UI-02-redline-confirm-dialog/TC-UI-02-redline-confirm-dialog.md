# TC-UI-02 — 命令红线确认与阻断对话框

## 基本信息

| 项 | 内容 |
| ---- | ---- |
| 用例编号 | TC-UI-02 |
| 类型 | UI 测试（TestFX，headless） |
| 关联 BR | BR-26~BR-32 |
| 关联模块 | BE-11 命令红线 / 安全、UI 对话框 |

## 测试目标

验证命令红线在 UI 层的确认/阻断交互：

- BLOCK 场景弹出阻断对话框，提示安全等价命令，仅允许「取消」
- CONFIRM 场景弹出确认对话框，显示风险详情，可「确认」/「取消」
- 操作记录到 `audit_log`（CONFIRMED/CANCELLED/BLOCKED）

## 前置条件

- 应用 TestFX headless 启动，打开测试仓库
- 预置保护分支 `main`、远程白名单、敏感文件规则
- 准备触发裸 force push、`reset --hard`、敏感文件提交的场景

## 测试步骤

| 步骤 | 操作 | 预期结果 |
| ---- | ---- | --------- |
| 1 | 触发裸 force push 到 `main` | 弹阻断对话框，提示「请改用 --force-with-lease」，操作被拒绝 |
| 2 | 触发暂存 `.env` 后 Commit | 弹阻断对话框，提示加入 .gitignore |
| 3 | 触发 `reset --hard` | 弹确认对话框，显示将丢失文件清单 |
| 4 | 确认对话框点「确认」 | 操作执行，audit_log 记 CONFIRMED |
| 5 | 确认对话框点「取消」 | 操作取消，audit_log 记 CANCELLED |
| 6 | 打开红线审计面板 | 可见上述记录 |

## 整体期望结果

- 阻断与确认对话框正确触发并显示风险
- 用户选择正确反映到 audit_log

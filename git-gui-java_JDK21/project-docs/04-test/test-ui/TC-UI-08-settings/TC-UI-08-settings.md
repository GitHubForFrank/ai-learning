| 项 | 内容 |
| ---- | ---- |

| 关联 BR | BR-27、BR-28、BR-37~BR-39 |

## 测试目标

验证设置页的配置项读写与即时生效。

## 前置条件

- 应用 TestFX headless 启动
- 设置页可打开

## 测试步骤

| 步骤 | 操作 | 预期结果 |
| ---- | ---- | --------- |
| 1 | 切换主题（浅色/深色/跟随系统） | 主题立即生效，无需重启 |
| 2 | 切换语言（中/英） | 界面语言立即切换 |
| 3 | 配置 Git 可执行文件路径 | 路径保存到 app_settings |
| 4 | 编辑保护分支清单（加 `release/*`） | 保存后红线规则读取新清单 |
| 5 | 编辑远程白名单 | 保存后推送白名单生效 |
| 6 | 自定义快捷键 | 持久化到 app_settings |
| 7 | 设置 per-repo user.name/email | 写入 `.git/config` |

## 整体期望结果

- 主题/语言即时生效
- 红线配置修改被规则读取
- 设置持久化到 app_settings / .git/config

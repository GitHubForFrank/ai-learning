# TC-UI-06 — 分支/标签管理

## 基本信息

| 项 | 内容 |
| ---- | ---- |
| 用例编号 | TC-UI-06 |
| 类型 | UI 测试（TestFX，headless） |
| 关联 BR | BR-12、BR-13 |
| 关联模块 | BE-04 分支标签 |

## 测试目标

验证分支与标签管理对话框的操作与校验。

## 前置条件

- 应用 TestFX headless 启动，打开有多分支的仓库

## 测试步骤

| 步骤 | 操作 | 预期结果 |
| ---- | ---- | --------- |
| 1 | 工作区不干净时切换分支 | 提示 stash/commit/abort |
| 2 | 创建新分支并切换 | 分支创建成功，当前分支切换 |
| 3 | 删除已合并本地分支 | 直接删除 |
| 4 | 删除未合并本地分支 | 二次确认 |
| 5 | 删除远程保护分支 | 红线阻断 |
| 6 | 创建/删除/推送标签 | 标签操作成功 |

## 整体期望结果

- 分支/标签操作校验与红线生效

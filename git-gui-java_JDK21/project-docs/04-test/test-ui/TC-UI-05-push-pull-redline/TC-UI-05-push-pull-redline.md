# TC-UI-05 — Push/Pull 流程（含红线闭环）

## 基本信息

| 项 | 内容 |
| ---- | ---- |
| 用例编号 | TC-UI-05 |
| 类型 | UI 测试（TestFX，headless） |
| 关联 BR | BR-09~BR-11、BR-26~BR-32 |
| 关联模块 | BE-03 远程同步、BE-11 命令红线 |

## 测试目标

验证 Push/Pull 对话框流程与命令红线端到端闭环。

## 前置条件

- 应用 TestFX headless 启动，打开有远程的仓库
- 预置保护分支与远程白名单

## 测试步骤

| 步骤 | 操作 | 预期结果 |
| ---- | ---- | --------- |
| 1 | 打开 Push 对话框，未选 remote | 提示选择 remote |
| 2 | 选 remote + 分支，force-with-lease 推送 | 推送执行，进度可取消 |
| 3 | 裸 force 推送到 `main` | 红线阻断对话框 |
| 4 | 推送到非白名单远程 | 红线阻断对话框 |
| 5 | Pull 对话框拉取 | 异步执行，完成后状态刷新 |
| 6 | 查看操作日志面板 | Push/Pull 记录入 operation_log |

## 整体期望结果

- Push/Pull 流程正常
- 红线闭环在 UI 端到端生效

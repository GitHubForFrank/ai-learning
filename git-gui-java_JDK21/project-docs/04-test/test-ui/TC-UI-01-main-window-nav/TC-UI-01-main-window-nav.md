# TC-UI-01 — 主窗口/导航树/多 Tab 切换

| 项 | 内容 |
| ---- | ---- |

| 类型 | UI 测试（TestFX，headless） |
| 关联 BR | — |

## 测试目标

验证主窗口架构：MenuBar + 导航树 + 多 Tab 内容区 + StatusBar 的加载与交互。

## 前置条件

- 应用以 TestFX headless 模式启动
- 预置一个测试仓库路径

## 测试步骤

| 步骤 | 操作 | 预期结果 |
| ---- | ---- | --------- |
| 1 | 启动应用 | 主窗口加载，MenuBar/导航树/StatusBar 可见 |
| 2 | 点击导航树某功能节点 | 内容区打开对应 Tab |
| 3 | 连续打开多个功能节点 | 多 Tab 共存，可切换 |
| 4 | 关闭某 Tab | Tab 关闭，内容区切换到相邻 Tab |
| 5 | StatusBar 显示当前仓库与状态 | 状态信息正确 |

## 整体期望结果

- 主窗口布局完整，导航与多 Tab 交互正常
- StatusBar 实时反映状态
